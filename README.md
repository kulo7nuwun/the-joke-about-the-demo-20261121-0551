# The joke about the demo

A one-line joke about working beside AI coding agents, written by a small
deterministic Python program for the
[make.fun](https://make.fun/c/the-joke-about-the-demo-20261121-0551)
competition "The joke about the demo".

Running `main.py` writes the joke to `/output/entry.txt`: a single line of
UTF-8 text, 1 to 280 characters, the same bytes on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
